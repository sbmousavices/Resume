## 💡 Resume Writing Best Practices

### Do's ✅

- **Use strong action verbs**: Led, Developed, Implemented, Achieved
- **Quantify achievements**: "Increased revenue by $500K"
- **Tailor for each job**: Match keywords from job description
- **Keep it concise**: 1 page for <10 years experience, 2 pages max
- **Use professional email**: firstname.lastname@email.com
- **Include LinkedIn URL**: Make it easy to find you online
- **Proofread multiple times**: Zero tolerance for typos

### Don'ts ❌

- **Don't use photos** (in US/UK/Canada)
- **Don't include personal info**: Age, marital status, religion
- **Don't use fancy fonts**: Stick to Arial, Calibri, Times New Roman
- **Don't use graphics/charts** for skills (ATS can't read them)
- **Don't list references**: "Available upon request" is enough
- **Don't use "I" or "my"**: Write in third person
- **Don't include salary expectations**: Discuss in interview

## 📈 Industry-Specific Tips

### For Tech/IT
- Highlight programming languages and frameworks
- Include GitHub/portfolio links
- List certifications (AWS, Azure, Google Cloud)
- Show impact metrics (performance improvements, cost savings)

### For Project Management
- Emphasize methodologies (Agile, Scrum, Waterfall)
- List project sizes and budgets managed
- Include PMP, PRINCE2, or other certifications
- Show team sizes and cross-functional leadership

### For Engineering
- Detail technical skills and software proficiency
- Include specific projects and your role
- List patents or publications if applicable
- Show cost savings or efficiency improvements

### For Creative Roles
- Include portfolio link prominently
- Show range of work (different styles/mediums)
- List client names (with permission)
- Highlight awards or recognition
